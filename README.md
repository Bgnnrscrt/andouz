# ⚡ ANDO Ecosystem (ando.uz)

Официальный веб-портал экосистемы **ANDO** — независимых премиальных приложений нового поколения для Android.

🌐 **Официальный сайт**: [https://ando.uz](https://ando.uz)  

---

## 📱 Продукты экосистемы

### 1. AndoGram (Telegram Mod)
Автономный защищённый клиент на базе AyuGram:
- **Личный Архив & Мост (A-B-C)** — двустороннее дублирование диалогов в приватный форум со второго телефона 24/7.
- **Обход No-Forwards** — скачивание любых защищённых медиа из каналов без тега автора и снятие `FLAG_SECURE`.
- **Honeypot-пароли** — ввод аварийного пин-кода скрывает секретные чаты под принуждением.
- **Сортировка по размеру** — поиск самых тяжёлых медиа в чатах и каналах через облачный MTProto сканер.
- **3D AR-маски** — MediaPipe аппаратный трекинг 468 точек лица в реальном времени.

### 2. Andusta (Instagram Mod)
Отдельный клон `com.andusta.android`, ставится рядом с Instagram, Root не нужен:
- **Ghost Mode** — истории и Direct без отметки «просмотрено», скрытие «печатает…».
- **Одноразовые фото** — не сгорают после первого просмотра, их можно открыть ещё раз.
- **Детектор отписок (тест)** — сверка подписчиков на телефоне, без пароля; в нынешней версии ещё не срабатывает, исправление — в следующем обновлении.
- **Своя музыка и голос** — свой трек при съёмке истории, смена голоса и свой трек вместо голоса в Direct.
- **Скачивание** — фото с текущего экрана в `Pictures/Andusta`, аватарка крупно по долгому нажатию.
- **Фото из галереи вместо камеры** — в моментальных снимках.
- **Анти-удаление в Direct** — тестовая функция, пока срабатывает не всегда.
- **Меньше рекламной слежки** — глушит часть рекламных запросов Instagram.

### 3. Andeo (видео- и аудиоплеер)
Локальный плеер `com.andeo.app` (Android 7.0+), отдельный проект владельца. На сайте с 10.11.2026, **ещё не в продаже** («Скоро в продаже»):
- **Сейф** — видео, музыка и папки шифруются (AES-256) и прячутся под PIN-кодом.
- **Неуязвимая корзина** — видео длиннее 3 с, удалённые в галерее, хранятся без срока; восстановление на прежнее место.
- **Переживает переустановку** — Сейф и корзина в скрытой папке телефона (нужен «Доступ ко всем файлам»).
- **Жесты** — яркость и громкость у краёв, переключение видео в центре, ускорение и перемотка назад удержанием пальца.
- **Музыка в фоне**, виджет, плейлисты, обрезка без перекодирования, звук из видео в M4A.

## 🛠️ Стек технологий портала

- **Фреймворк**: React 19 + Vite 8 + TypeScript 7, линтер oxlint
- **Стилизация**: Ванильный CSS (CSS Custom Properties, Glassmorphism, Neon Cyberpunk)
- **Анимации**: [`motion`](https://motion.dev), canvas-фон с частицами, CSS-анимации
- **Иконки**: `lucide-react`
- **Эффекты**: `canvas-confetti`, `qrcode.react` (QR-код для скачивания)
- **Инфраструктура**: Vercel Serverless Edge CDN + aHOST.uz DNS (`ando.uz`)
- **Языки**: Русский (`ru`), Узбекский (`uz`), Английский (`en`)

## 🧑‍💻 Разработка

```bash
npm install
npm run dev      # локальный сервер с HMR
npm run build    # проверка типов + продакшн-сборка в dist/
npm run lint
```

```
src/
  App.tsx              страница, язык, модалки (грузятся лениво)
  data.ts              приложения, сравнения, ссылки на APK (DOWNLOAD_URLS), промокоды
  lib/motion.ts        токены анимаций: кривые, длительности, пружины
  hooks/               useMediaQuery / useCanHover, useTilt (3D-наклон)
  components/fx/       Reveal / Stagger (появление при скролле), ScrambleText, spotlight
  components/ui/       SectionHeader, SegmentedControl (вкладки), Modal
  components/hero/     фон с частицами, эмблема, заголовок, «магнитная» кнопка
  components/demo/     сцены интерактивного демо телефона
```

Правила анимаций: анимируются только `transform`/`opacity`, кривые и длительности берутся из `src/lib/motion.ts`, hover-эффекты только для мыши, `prefers-reduced-motion` учитывается везде, canvas ставится на паузу вне экрана.
